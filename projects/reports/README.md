# 🚀 Project Handoff Guardian

Project Handoff Guardian is a simple project management tool that creates a structured handoff report from project information.

## 🎯 Problem

When a project is transferred to another person, important information can easily be missed.

This project organizes important project knowledge into one simple handoff report.

## 🚀 Day 1 Features

- Enter project name
- Enter current owner
- Record completed work
- Record work in progress
- Record blockers
- Record important decisions
- Record next actions
- Generate a structured handoff report

## 🛠️ Technologies

- Python
- Git
- GitHub

## ▶️ How to Run

```bash
python app.py
```

## 📊 Example

```text
PROJECT HANDOFF REPORT

Project: AI Portfolio
Current Owner: Srushti

COMPLETED WORK
Homepage and resume section

WORK IN PROGRESS
Contact form

BLOCKERS
Email API not configured

IMPORTANT DECISIONS
React selected for frontend

NEXT ACTIONS
Configure email API and test contact form
```
